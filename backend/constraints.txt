# Why this file exists
# --------------------
# Stage 4F-G's dependency review found that `pip-audit -r requirements.txt`
# and the image disagreed: locally `starlette` resolved to 0.49.3, in the
# container to 0.52.1, and `click` to two different versions with different
# advisories. Direct dependencies were pinned; the two dozen transitives they
# pull were not, so "what was audited" and "what runs" were different
# questions and only one of them was being asked.
#
# Applied with `pip install -c constraints.txt`, so it pins versions without
# requiring anything to be installed -- the dev-only packages listed here are
# constrained if present and absent from the runtime image either way.
#
# Regenerate deliberately, from the image, after any dependency change:
#
#     docker compose exec -T backend pip freeze | sort
#
